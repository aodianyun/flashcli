FlashServer API

本地模型调度服务 · http://localhost:8790 · 权威契约：openapi.yaml

认证

默认关闭。配置了 token 时，除 /health、/docs、/openapi.yaml、/ 外需要 X-Flashcli-Token: <token> 或 Authorization: Bearer <token>。

系统与资源

方法路径说明
GET/health存活检查
GET/v1/system系统、GPU/CPU/内存、CUDA/SM/torch、开机启动状态
GET/v1/gpuGPU 设备与 CUDA 进程
GET/v1/gpu/history?seconds=300GPU/CPU 遥测历史
GET/v1/resources准入视图（GPU/已加载/槽位）
GET/v1/models本地缓存模型
GET/v1/models/loaded已加载模型
GET/v1/storage磁盘占用
GET/v1/logs?kind=server|model&ref=...&lines=200日志（journalctl tail，最多 2000 行）
GET/v1/logs/download?kind=server|model&ref=...下载完整日志
GET/v1/wsWebSocket：1Hz 系统快照 + 任务进度

FlashHub 目录

方法路径说明
GET/v1/catalog?q=pi05&tag=1&sort=updated&page=1&page_size=20搜索仓库
GET/v1/catalog/tags分类列表
GET/v1/catalog/{id}仓库详情 + 版本列表

模型生命周期

方法路径说明
POST/v1/models/load{"ref":"flashcli-bundle/name:version","async":true}
POST/v1/models/unload{"ref":"..."}
POST/v1/pull下载 bundle/权重（异步任务）
GET/v1/jobs/{id}任务状态
GET/v1/jobs/{id}/events任务进度 SSE

示例

# 加载模型（异步）
curl -X POST http://localhost:8790/v1/models/load \
  -H 'Content-Type: application/json' \
  -d '{"ref":"flashcli-bundle/qwen3_8b_nvfp4:1.0.0","async":true}'

# 查询任务
curl http://localhost:8790/v1/jobs/load-1

# 推理：使用 load 返回的 endpoint
curl http://localhost:PORT/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3","messages":[{"role":"user","content":"Hello"}]}'
