FlashServer API

本地模型调度服务 · http://localhost:8790 · 权威契约：openapi.yaml
基础 系统与模型 加载与任务 FlashHub 目录 日志 WebSocket 推理 端点总览

基础约定

项目值说明
Base URLhttp://localhost:8790默认仅监听本机回环地址。
Content-Typeapplication/json所有 POST 请求体为 JSON。
鉴权默认关闭开启后需要 X-Flashcli-Token: <token> 或 Authorization: Bearer <token>；/health、/docs、/openapi.yaml、/ 不需要。
错误格式{"error":"..."}HTTP 4xx/5xx 时返回。

错误示例

HTTP/1.1 400 Bad Request
Content-Type: application/json

{"error":"ref is required"}

加载与任务

POST/v1/models/load

加载模型并启动推理服务。FlashHub 引用在首次加载时自动拉取 bundle/权重。

请求参数

字段类型说明
refstring必填。如 flashcli-bundle/qwen3_8b_nvfp4:1.0.6。
asyncbool默认 true，返回 job_id。

请求示例

curl -X POST http://localhost:8790/v1/models/load \
  -H 'Content-Type: application/json' \
  -d '{"ref":"flashcli-bundle/qwen3_8b_nvfp4:1.0.6","async":true}'

响应示例（202）

{"job_id":"load-1","state":"running"}

GET/v1/jobs/{id}

查询任务状态和事件历史。events[].phase 常见值：resolve、runtime、weights、progress、done、failed。

{
  "id": "load-1", "type": "load",
  "ref": "flashcli-bundle/qwen3_8b_nvfp4:1.0.6",
  "state": "running",
  "events": [
    {"time":"2026-11-10T02:31:02Z","phase":"resolve","message":"resolving bundle"},
    {"time":"2026-11-10T02:31:10Z","phase":"weights","message":"downloading 42%"},
    {"time":"2026-11-10T02:31:20Z","phase":"progress","message":"loading weights"}
  ]
}

GET/v1/jobs/{id}/events

任务进度 SSE 流；事件结束时连接关闭。

event: progress
data: {"time":"2026-11-10T02:31:10Z","phase":"weights","message":"downloading 42%"}

event: progress
data: {"time":"2026-11-10T02:31:20Z","phase":"progress","message":"loading weights"}

event: done
data: {"time":"2026-11-10T02:31:26Z","phase":"done"}

POST/v1/models/unload

停止推理服务并释放进程；权重缓存保留。

{"ref":"flashcli-bundle/qwen3_8b_nvfp4:1.0.6"}
{"ok":true}

POST/v1/pull

异步下载 bundle、运行时和权重，不启动推理服务。

{"ref":"flashcli-bundle/qwen3_8b_nvfp4:1.0.6"}
{"job_id":"pull-1","state":"running"}

FlashHub 目录

GET/v1/catalog

代理公共 FlashHub 仓库搜索。

查询参数

参数类型说明
qstring按仓库名搜索，如 pi05。
tagint分类 id，来自 /v1/catalog/tags。
sortstringupdated（默认）或 downloads。
pageint从 1 开始。
page_sizeint默认 20，最大 100。

日志

GET/v1/logs

读取服务或模型日志（服务日志来自 journalctl -u flashserver）。

查询参数

参数类型说明
kindstringserver（默认）或 model。
refstringkind=model 时必填。
linesint默认 200，最大 2000。
sinceintUnix 秒；只返回该时间之后的服务日志（用于清空后只看新日志）。
{
  "kind": "server",
  "lines": [
    "2026-11-10T10:30:55+08:00 lin-homepc systemd[1]: Started flashserver.service",
    "2026-11-10T10:30:55+08:00 lin-homepc flashserver[224521]: listening on http://0.0.0.0:8790"
  ]
}

GET/v1/logs/download

完整日志附件（text/plain，Content-Disposition: attachment）。参数同上；kind=model 时需要 ref。

curl -o flashserver.log 'http://localhost:8790/v1/logs/download?kind=server'

推理

POST{endpoint}/v1/chat/completions

模型进程提供 OpenAI 兼容接口。endpoint 来自加载响应或 /v1/models/loaded，不要写死端口。

curl http://127.0.0.1:49152/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": true
  }'
推理 API 由 bundle 自己实现；能力（流式、工具调用、视觉输入等）取决于模型与 bundle。
